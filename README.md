# iCreate Calendar

Separate Work module for schedules, invites and shared calendars. **Not** Thunderbird Lightning
inside iCreate Email.

| Item | Choice |
|------|--------|
| Status | Research (catalogue) |
| Licence target | MIT or Apache-2.0 for iCreate-owned code |
| Data | Local-first SQLite / ICS; credentials in OS keychain |
| Sync | Off by default; optional later opt-in |
| Bundle (intended) | `za.co.icreativate.icreate-calendar` |

See [docs/architecture.md](docs/architecture.md) for the phased plan. No installer until research
graduates and a real update channel exists — launcher shows **Research**, never Install.
